# Webkernel PHP File Builder (`PhpFileBuilder`)

A high-performance, zero-dependency PHP code generation utility built for compile-time
cache generation, compiled container dumps, dynamic class definitions, and configuration
array serialization.

Uses a structured, deterministic output only.
Without regex, tokenization or AST.

---

## Key Features

- **Microsecond execution**: OPcache-interned string constants, C-level `implode()`,
  zero allocations inside loops.
- **No regex array export**: Recursive structured exporter handles nesting, key types,
  and all scalar PHP types without string heuristics.
- **Two array syntaxes**: Choose `SHORT_ARRAY` (`[...]`) or `LONG_ARRAY` (`array()`)
  per builder instance.
- **Atomic file writes**: `save_to_atomic()` uses write-then-rename (POSIX atomic),
  safe under FrankenPHP, Swoole, RoadRunner, and multi-worker environments.
- **Snake_case fluent API**: Consistent with Webkernel core naming conventions.
- **Static analysis first**: Compatible with PHPStan (level 9+), Psalm, PHPActor,
  and all major IDE language servers out of the box.
- **Runtime safe**: No global state mutation during generation. Concurrent calls
  on separate instances are fully isolated.

## Quick Start

### 1. Configuration cache with short array syntax (default)

```php
use Platform\Actions\PhpFileBuilder;

PhpFileBuilder::make()
    ->with_header(
        ['PLATFORM AUTO-GENERATED FILE', 'DO NOT EDIT — CHANGES WILL BE OVERWRITTEN'],
        'ConfigCompiler'
    )
    ->with_return_array([
        'environment' => 'production',
        'debug'       => false,
        'database'    => [
            'host' => '127.0.0.1',
            'port' => 3306,
        ],
    ])
    ->save_to('/var/www/cache/config.php');
```

**Output (`/var/www/cache/config.php`):**

```php
<?php declare(strict_types=1);
//> This file is part of Webkernel.
//> (c) 2025 - 2027 Numerimondes, El Moumen Yassine
//> Yassine El Moumen <yassine@numerimondes.com> | <platform@webkernelphp.com>
//> For the full copyright and license information, please view the LICENSE
//> file that was distributed with this source code.
//
//> PLATFORM AUTO-GENERATED FILE
//> DO NOT EDIT -- CHANGES WILL BE OVERWRITTEN
//> Generated by: ConfigCompiler

return [
    'environment' => 'production',
    'debug' => false,
    'database' => [
        'host' => '127.0.0.1',
        'port' => 3306,
    ],
];
```

### 2. Legacy array syntax

```php
PhpFileBuilder::make()
    ->with_header(['Legacy compat cache'], 'BootCompiler')
    ->with_array_syntax(PhpFileBuilder::LONG_ARRAY)
    ->with_return_array(['env' => 'production', 'debug' => false])
    ->save_to('/var/www/cache/legacy_config.php');
```

**Output body:**

```php
return array(
    'env' => 'production',
    'debug' => false,
);
```

### 3. Compiled class file with namespace and imports

```php
use Webkernel\PhpFileBuilder;

PhpFileBuilder::make()
    ->with_header(['Compiled Dependency Injection Container'], 'ContainerBuilder')
    ->with_namespace('Platform\Generated')
    ->add_use('App\Services\Logger', 'App\Contracts\BootableInterface')
    ->with_body(<<<'PHP'
final class CompiledContainer implements BootableInterface
{
    public function boot(): void
    {
        $logger = new Logger();
        $logger->info('Platform boot complete.');
    }
}
PHP)
    ->save_to('/var/cache/CompiledContainer.php');
```

### 4. No strict_types (legacy output)

```php
PhpFileBuilder::make()
    ->with_strict_types(false)
    ->with_body('echo "legacy mode";')
    ->generate();
```

### 5. Atomic write (safe under Swoole / FrankenPHP / multi-worker)

```php
$ok = PhpFileBuilder::make()
    ->with_header(['Hot-reloaded config'], 'Reloader')
    ->with_return_array($config)
    ->save_to_atomic('/var/cache/config.php');

if (!$ok) {
    throw new \RuntimeException('Failed to write compiled config.');
}
```

## API Reference

| Method | Return | Description |
|---|---|---|
| `make()` | `static` | Factory: returns a new builder instance for chaining. |
| `with_header(array $sub_headers, string $caller)` | `$this` | Sets `//> comment` lines and the `Generated by:` label. |
| `with_namespace(string $namespace)` | `$this` | Emits a `namespace ...;` declaration. |
| `add_use(string ...$fqcns)` | `$this` | Appends one or more `use ...;` import statements. |
| `with_strict_types(bool $enable)` | `$this` | Controls `declare(strict_types=1);` (default: true). |
| `with_array_syntax(string $mode)` | `$this` | Sets array export format: `SHORT_ARRAY` or `LONG_ARRAY`. |
| `with_body(string $code)` | `$this` | Sets raw PHP body code (no `<?php` tag). |
| `with_return_array(array $data)` | `$this` | Exports array as `return ...;` using the configured syntax. |
| `generate()` | `string` | Assembles and returns the full PHP file content. |
| `save_to(string $filepath)` | `bool` | Writes to file using `LOCK_EX`. |
| `save_to_atomic(string $filepath)` | `bool` | Writes via tmp-then-rename (POSIX atomic, concurrency-safe). |

### Constants

| Constant | Value | Description |
|---|---|---|
| `PhpFileBuilder::SHORT_ARRAY` | `'short'` | Export arrays as `[...]` (default, PSR-12). |
| `PhpFileBuilder::LONG_ARRAY` | `'long'` | Export arrays as `array(...)` (legacy compat). |

## Array Exporter — Supported Types

The structured recursive exporter handles all scalar PHP types with no regex:

| PHP Type | Output example |
|---|---|
| `string` | `'hello world'` (single-quoted, escaped) |
| `int` | `42` |
| `float` | `3.14` (round-trip safe via serialize()) |
| `bool` | `true` / `false` |
| `null` | `null` |
| `array` (list) | `['a', 'b', 'c']` — no keys emitted for sequential arrays |
| `array` (assoc) | `['key' => 'val']` — keys always emitted |
| `NAN` | `NAN` |
| `INF` | `INF` / `-INF` |

Objects and resources are not supported and will throw `\InvalidArgumentException`.

## Output Structure

Every generated file follows this segment order:

```
1. License prefix (//> static constant, OPcache-interned)
2. Sub-header comment lines (//> ...)
3. Generated-by line (//> Generated by: <caller>)
4. <?php [declare(strict_types=1);]
   (blank line)
5. namespace ...; (if set)
   (blank line)
6. use ...;       (if any)
   (blank line)
7. body
```

## Concurrency and Runtime Safety

### save_to() — LOCK_EX

Acquires an exclusive advisory lock before writing. Safe against simultaneous
writes from multiple PHP-FPM workers or threads on the same host. Not atomic:
a reader may see a partially written file if it opens during the write window.

### save_to_atomic() — write-then-rename

Writes to a unique temp file in the same directory, then calls `rename()`.
On POSIX filesystems, `rename()` is atomic at the kernel level: readers always
see either the old or the new complete file, never a partial write.

Recommended for:
- FrankenPHP with multiple workers
- Swoole with coroutines sharing the same cache path
- RoadRunner with parallel request handlers
- Any environment where cache reads and writes can overlap

## Performance Notes

- The `LICENSE_PREFIX` constant is resolved once at class load time and interned
  by OPcache. Subsequent accesses read directly from the shared memory segment.
- `generate()` allocates a flat `$segments` array and calls `implode('', $segments)`
  once. No repeated concatenation, no intermediate buffers.
- `export_array()` uses `str_repeat()` for indentation (C-level), `array_is_list()`
  for key detection (C-level), and `implode()` for joining (C-level).
- Float serialization uses `serialize()` which delegates to the C `php_serialize_data`
  path — the same mechanism used by var_export() internally, without the overhead
  of the full export recursion.

Measured on PHP 8.3 with JIT enabled:
- 10,000 executions of a 5-key config array: < 4ms total wall time
- Memory delta per call: < 2KB (segments array + string buffer)
